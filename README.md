# Blog REST API

## Overview
This project is a RESTful API for a blog application, built using **Node.js**. It provides endpoints for managing users, posts, comments, and other blog-related functionalities. The API follows best practices for REST architecture, including proper status codes, error handling, and authentication.

## Features
- **User Management:** Register, login, and manage user profiles  
- **Blog Posts:** Create, read, update, and delete posts  
- **Comments:** Add, update, and delete comments on posts  
- **Authentication:** JWT-based authentication for secure access  
- **Validation & Error Handling:** Ensures data integrity and provides meaningful error messages  
- **Modular Architecture:** Organized codebase for scalability and maintainability  

## Tech Stack
- **Backend:** Node.js, Express.js  
- **Database:** MongoDB (with Mongoose ORM)  
- **Authentication:** JSON Web Tokens (JWT)  
- **Testing:** Jest / Postman (for API testing)  
- **Other Tools:** dotenv for environment variables, bcrypt for password hashin
